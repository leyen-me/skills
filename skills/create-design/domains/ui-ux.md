# Domain Adapter：UI / UX

## 领域特有关注
用户目标、任务流、信息架构、导航、可发现性、反馈、错误恢复、响应式布局、输入方式、可访问性、性能和状态完整性。

## 必须覆盖的状态
默认、悬停（适用时）、焦点、按下、加载、成功、错误、禁用、空状态、离线/权限异常（适用时）。

## 工作重点
- 从用户任务和情境开始，而不是从组件库开始。
- 先设计流程和信息结构，再设计视觉系统。
- 关键操作应有明确的可发现性、反馈和恢复路径。
- 键盘、触屏、读屏和不同屏幕尺寸应纳入设计。
- 用真实任务测试验证，而不是只凭截图判断。

## 常见误区
只有漂亮首页没有完整状态；Hover 才能发现关键功能；用颜色作为唯一状态信号；为了动效牺牲速度和可控性。
