# Composition Patterns：构成模式

模式是可复用的关系结构，不是固定模板。

## 1. 主体 + 支撑信息
一个明确主角，周围信息支持其理解。适用于主视觉、产品主张、关键场景。
风险：主体过强而缺乏上下文。

## 2. 对照 / 双极结构
通过两组内容形成差异、冲突或选择。适用于前后对比、观点对照、方案比较。
风险：人为制造虚假二元对立。

## 3. 序列 / 时间线
以顺序组织步骤、故事或变化。适用于流程、视频、教程、历史叙事。
风险：把非线性内容强行线性化。

## 4. 网格 / 模块
重复结构支持扫描、比较和扩展。适用于目录、仪表盘、编辑版面。
风险：内容被迫适应模块，造成单调。

## 5. 沉浸式场景
让主体、环境、声音、运动和叙事形成连续体验。适用于展览、品牌体验、影像和空间。
风险：牺牲可控性、可读性或设备性能。

## 6. 聚焦 / 留白
通过减少周围竞争建立注意力和情绪空间。适用于高价值信息、仪式性表达、品牌主视觉。
风险：信息不足或空白失去意图。

## 使用规则
先确认模式解决的问题，再调整其比例、节奏、密度和视觉语言。不要因为模式流行就默认使用。
