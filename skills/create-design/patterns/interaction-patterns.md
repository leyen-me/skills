# Interaction Patterns：交互模式

## 状态是设计的一部分
每个可交互对象至少考虑：默认、悬停（适用设备时）、焦点、按下、加载、成功、错误、禁用和空状态。

## 常见模式
- 即时反馈：操作后立即给出可理解反馈。
- 渐进披露：先呈现当前所需信息，复杂选项按需展开。
- 撤销与恢复：降低操作风险。
- 骨架屏/加载：解释等待过程，不制造虚假进度。
- 空状态：说明当前状态、原因和下一步。
- 错误恢复：指出问题并提供可行修复路径。
- 引导式首次体验：帮助用户完成首个有价值任务。

## Hover 原则
Hover 不能成为唯一的信息入口或唯一操作方式；触屏、键盘和辅助技术用户需要等价路径。
