# Creation Workflow：创作工作流

## 1. Brief
明确目标、受众、内容、媒介、场景、约束和成功标准。

## 2. Explore
生成至少两个具有真实策略差异的方向；任务很小或约束极强时可缩减。

## 3. Decide
比较方向的目标契合、独特性、可行性、可访问性和风险。写出关键决策理由。

## 4. Structure
建立信息架构、构图、网格、叙事顺序、空间路径或时间结构。

## 5. Language
确定色彩、字体、形态、材质、光线、声音和运动等表达语言。

## 6. Build
按媒介制作：组件、页面、分镜、镜头、模型、原型、实体样机等。

## 7. Polish
检查细节、状态、边界、性能、适配和交付规格。

## 8. Critique
用评价协议识别根因，进行有针对性的迭代。
