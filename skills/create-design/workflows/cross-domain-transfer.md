# Cross-domain Transfer：跨领域迁移

## 迁移原则
迁移的是设计问题结构与关系原理，不是表面形式。

## 例子：视觉层级
- 海报：尺寸、位置、对比和留白控制阅读顺序。
- UI：标题、内容、操作和状态形成可扫描层级。
- 视频：镜头尺度、运动、焦点和剪辑节奏安排注意力。
- 3D：构图、灯光、景深、材质和空间位置突出主体。
- 展览：动线、尺度、照明和信息密度组织参观路径。

## 迁移检查
1. 原理在新媒介中仍然解决同类问题吗？
2. 新媒介增加了哪些维度（时间、身体、声音、物理约束）？
3. 哪些旧方法不再适用？
4. 是否需要新的评价方式？
5. 迁移后是否有真实测试或制作验证？
