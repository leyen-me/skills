# Layout Grammar：布局与网格

网格是组织关系的工具，不是必须看得见的线框。

## 网格类型
- 单栏：连续阅读、沉浸叙事。
- 多栏：复杂信息、灵活组合。
- 模块网格：内容卡片化、模块化编排。
- 基线网格：文字节奏和纵向对齐。
- 层级网格：编辑性、非对称、强调内容差异。
- 空间/建筑网格：结构、动线、尺度与功能分区。

## 决策变量
内容复杂度、屏幕/画幅尺寸、阅读方向、响应式变化、内容长度、可访问性、品牌个性。

## 检查
- 对齐是否有系统？
- 断点/画幅变化时结构是否仍成立？
- 是否有足够变化避免机械重复？
- 留白是否帮助分组、强调和呼吸？
- 是否存在孤立元素、尴尬断行或不必要的空洞？
