# Composition Grammar：构成语法

## 构成变量
- 位置：中心、偏心、边缘、轴线、对齐关系
- 尺度：主次比例、大小差异、尺度突变
- 方向：水平、垂直、斜向、径向、视线方向
- 密度：元素数量、信息密度、空隙密度
- 平衡：对称、非对称、视觉重量分配
- 节奏：重复、间隔、渐变、突变、停顿
- 框架：边界、裁切、出血、画幅、视窗
- 深度：重叠、透视、景深、明暗层次

## 常见结构策略
- 对称：稳定、仪式感、秩序；风险是僵硬。
- 非对称：动态、个性、张力；风险是失衡。
- 中心聚焦：明确主体；风险是缺少方向性。
- 对角线：运动和张力；风险是阅读不稳定。
- 模块网格：秩序和扩展；风险是模板化。
- 破格：强调重点、制造意外；风险是破坏可读性。

## 设计步骤
1. 确定画幅/空间边界。
2. 标记主要信息或视觉主体。
3. 建立主轴、网格或结构关系。
4. 分配视觉重量和负空间。
5. 检查缩小、远看、快速浏览时的整体轮廓。
6. 再安排局部细节。
