# Color Grammar：色彩语法

## 色彩不是装饰
色彩承担识别、分组、层级、情绪、象征、材料暗示和品牌记忆等功能。

## 主要变量
- 色相：色彩类别与文化联想
- 明度：亮暗层级、空间感和可读性
- 饱和度：强度、活跃度和视觉重量
- 色温：冷暖倾向
- 面积：颜色占比会改变整体感受
- 邻接关系：背景、文字、图像和周边颜色会改变感知

## 配色组织方式
单色、类似色、互补、分裂互补、三角色、冷暖对照、低彩度中性色加重点色等。它们是起点，不是保证好看的公式。

## 工作流程
1. 明确情绪、品牌和信息功能。
2. 先确定明度结构，再精调色相与饱和度。
3. 为背景、主体、次级信息、强调和状态建立角色。
4. 检查不同显示设备、环境光和色觉差异。
5. 文字与重要 UI 信息按适用标准验证对比度。
6. 不只依赖颜色传递错误、成功或状态信息。
