# Example：视觉层级如何跨媒介迁移

## 共享问题
有限的注意力如何被组织，使受众优先感知与目标最相关的信息？

## 共通机制
通过差异和关系建立优先级。差异可以是尺度、位置、对比、密度、运动、声音、空间距离或持续时间。

## 平面海报
标题、主体图像、说明文字和行动信息建立阅读顺序。需要测试缩略图和远距离识别。

## UI
标题、内容、主要操作和状态提示建立扫描路径。必须同时考虑键盘焦点、触屏和读屏语义。

## 视频
镜头尺度、焦点、运动方向、声音和剪辑节奏决定观众在某一时刻关注什么。需要考虑字幕和静音观看。

## 3D
主体位置、轮廓、灯光、材质对比、景深和相机运动建立空间注意力。需要在目标视点和实时性能下验证。

## 不能直接迁移的部分
海报的静态阅读路径不能直接等同于视频的时间顺序；UI 的操作可发现性也不能仅凭视觉层级解决。共享的是注意力组织问题，具体手段与验证方式不同。
