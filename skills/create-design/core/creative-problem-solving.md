# Creative Problem Solving

## 生成多个真正不同的方向
方向差异应来自概念、叙事、结构、感知策略或媒介使用，而不是只换颜色和字体。

示例方向：
- 信息优先：清晰、可扫描、低认知成本。
- 情绪优先：氛围、象征、感官节奏。
- 叙事优先：通过顺序、揭示和转折建立体验。
- 系统优先：模块化、可扩展、跨触点一致。
- 实验优先：挑战惯例，但明确风险与可理解性边界。

## 选择
先排除违反硬约束的方向，再比较软目标。不要用虚假的精确分数掩盖价值取舍。

## 创新
创新可以来自新组合、新关系、新视角、新工艺、新媒介，或对既有惯例的有理由偏离。仅仅增加装饰或使用新潮效果不构成可靠创新。
