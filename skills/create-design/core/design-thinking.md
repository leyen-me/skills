# Design Thinking：设计作为有目的的决策

## 定义
设计是面对特定目标、受众、情境和约束，对信息、形式、行为、空间或时间进行有意组织，并通过表达与验证产生价值的过程。

## 通用循环
观察 → 定义问题 → 建立假设 → 生成方向 → 选择策略 → 制作表达 → 获取反馈 → 修订。

这不是严格线性流程。研究可能在制作中继续，原型可能暴露错误的问题定义，评价也可能促使概念重构。

## 三种思维同时工作
- 发散：扩大可能性，探索不同概念和表达。
- 收敛：根据目标、约束和证据做选择。
- 反思：检查自己是否误读问题、过度依赖惯例或忽视受众。

## 好的设计问题
好的问题陈述包含对象、情境、目标和限制；避免预先把解决方案写进问题。
错误：“做一个有高级感的玻璃拟态网页。”
更好：“为首次访问的专业用户设计一个产品介绍体验，使其在短时间内理解核心价值并找到试用入口；品牌需要可信、克制且有技术感。”

## 设计质量不是单维度
功能、意义、审美、可理解性、可访问性、可制造性、可持续性和文化适切性可能相互促进，也可能冲突。设计师的工作包括识别冲突并作出透明取舍。
