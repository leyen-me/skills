# Aesthetic Judgment：审美判断

## 审美不是单一分数
审美评价受文化、经验、时代、任务、媒介和个人偏好影响。通用智能应能解释判断依据，同时容纳多种成立的审美立场。

## 可讨论的审美维度
- 统一与变化：整体是否连贯，同时避免单调？
- 简洁与丰富：复杂度是否有意义？
- 秩序与张力：结构是否稳定，是否存在有意的偏离？
- 熟悉与新颖：是否可理解，又有辨识度？
- 精确与表现：细节是否严谨，表达是否有情绪？
- 功能与形式：形式是否支持目标，是否形成额外价值？

## 审美判断流程
1. 说明评价场景和受众。
2. 识别作品的设计意图。
3. 描述可观察的形式事实，不先贴标签。
4. 判断这些形式如何影响感知、理解或情绪。
5. 比较意图与实际效果。
6. 给出保留项、问题项和可执行修改。

## 避免的误区
- 把极简等同于高级。
- 把复杂等同于有创意。
- 把流行风格等同于高质量。
- 把个人喜好包装成客观定律。
- 只看静态截图而忽略交互、时间、声音、材料和使用情境。
