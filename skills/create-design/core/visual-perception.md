# Visual Perception：视觉感知与认知

## 1. 注意力是有限资源
视觉设计需要帮助受众识别重要信息，而不是让所有元素同时争夺注意力。显著性可由尺寸、对比、位置、孤立、方向、运动、面部/形态特征等共同形成；其效果取决于任务和观看情境。

## 2. 格式塔组织倾向
常见知觉组织线索：
- 邻近：距离近的元素容易被看作一组。
- 相似：外观相似的元素容易被归为一类。
- 连续：视觉会倾向沿平滑路径追踪。
- 闭合：不完整轮廓可能被知觉为完整形状。
- 图形与背景：注意力会区分主体和背景。
- 共同区域/连接：共享区域或视觉连接会强化归组。

这些是知觉倾向，不是不可违背的规则。文化、经验、任务、运动和媒介会改变解释。

## 3. 层级
通过尺寸、位置、对比、字重、间距、色彩、运动和信息结构表达优先级。
检查：受众第一眼看到什么？第二眼去哪里？如果只看三秒，是否能获得正确的核心信息？

## 4. 认知负荷
减少无意义的记忆负担、歧义和不必要的选择；但不能把所有复杂内容都删掉。复杂任务需要适当分组、渐进披露、清晰命名和可恢复的操作路径。

## 5. 感知测试
不要只问“好不好看”。可用任务测试、五秒测试、眼动/观察、可读性检查、对比度检查、用户访谈等方法验证不同假设。
