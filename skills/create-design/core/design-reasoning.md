# Design Reasoning：设计推理

## 设计选择的证据层级
1. 明确需求与硬约束
2. 目标受众和真实使用情境
3. 用户研究、测试或生产数据
4. 可追溯的专业原则与研究
5. 同类案例和历史经验
6. 设计师判断与可检验假设

不同任务的证据权重不同。实验数据也需要解释，不能脱离情境机械套用。

## 决策矩阵
对候选方向比较：
- 目标契合
- 受众理解
- 识别度/差异性
- 可访问性与包容性
- 技术/生产可行性
- 长期维护与一致性
- 风险和代价

## 反事实检查
- 如果删掉这个元素，目标会受损吗？
- 如果受众、文化或媒介改变，方案还成立吗？
- 是否存在更简单或更直接的表达？
- 是否有某种偏好在支配决策，却没有证据？
- 哪个设计决定最可能导致失败？
