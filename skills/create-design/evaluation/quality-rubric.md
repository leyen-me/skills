# Quality Rubric：质量量表

每项可用 1–5 级描述，但必须附证据，不应把总分当作绝对审美结论。

1 = 严重不成立；2 = 明显不足；3 = 基本成立但有改进空间；4 = 成熟有效；5 = 在当前目标和约束下表现突出。

| 维度 | 关键问题 |
|---|---|
| 目标契合 | 作品是否完成预期任务？ |
| 概念 | 是否有清楚且贯穿的主张？ |
| 层级 | 注意力顺序是否合理？ |
| 构成 | 结构、比例、节奏是否成立？ |
| 表达 | 视觉/感官语言是否适切？ |
| 一致性 | 规则是否连贯，变化是否有意图？ |
| 可访问性 | 是否存在可避免的参与障碍？ |
| 媒介适配 | 技术和物理条件是否被考虑？ |
| 独特性 | 是否避免无理由的模板化？ |
| 完成度 | 细节和边界是否可靠？ |

建议同时输出：
- 最强的三个方面
- 最重要的三个问题
- 一个优先级最高的修改动作
- 仍需真实用户/专家/生产验证的假设
