# Skills

## 中文

这里是我个人平时积累的一些 Skill。

平时做项目时会把自己踩过的坑、验证过的做法、写过的规范整理成一份份可以反复使用的文档，放在这里。它们不是代码库，也不是教程，而是写给 Agent（也写给未来的我自己）读的东西——下次遇到同样的场景，直接加载就能用，不用重新整理一遍。

会陆续更新，内容偏个人经验，不一定通用。

## English

This is a personal collection of skills I accumulate over time.

When I work on a project, I write down the pitfalls I hit and the approaches that actually held up, so they can be reused instead of re-derived. These are not codebases or tutorials — they are documents meant to be read by an agent (and by future me), loaded on demand when a similar situation comes up again.

Personal experience, updated as I go, not necessarily general.
